## 三大研究视角

| 视角 | 核心问题 | 
|------|---------|
| **企业维度（微观）** | 头部企业怎么做的？逐一建立"一张画像" |


## 企业画像十一维（完整流程）

### 前置判断
- **重资产还是轻资产？** 重资产走完整流程，轻资产聚焦品牌授权/代建合同/分账结构
- **核心业态是哪个？** 自动跳过不相关业态

### 三种输入模式
| 输入 | 做法 |
|------|------|
| "我有材料" | 全量画像，交叉验证 |
| "只知道公司名" | 先搜工商信息，再补充 |
| "帮客户做的" | 以材料为主，标注缺失 |

### 自动建档七步
```
第一步：工商穿透 → 股权结构树 + 注册资本(实缴/认缴)
第二步：核心人物 → 法人/董事/监事 + 家族/职业经理人标注
第三步：产业板块 → 核心/配套/试水/已退出分类
第四步：项目建档 → 逐个项目信息
第五步：对外关系 → 协会商会+合资合作+政企合作
第六步：可靠性标注 → （确认）/（推断）/（矛盾）
第七步：持续迭代 → 新信息自动回填
```

### 深度画像补充（步骤8-12）

**步骤8：融资结构穿透**
- 股东借款/银行授信/信托/债券/外资/表外负债
- 侧面印证：发债记录、股权质押、商票逾期、供应商诉讼
- 标注融资渠道集中度风险

**步骤9：现金流与再融资能力**
- 短期到期债务规模与现金覆盖倍数（定性）
- 销售回款率趋势、资产抵押率
- 标注：再融资风险等级（低/中/高，推断）

**步骤10：资产退出路径**
- 每个核心项目标注退出路径：散售/整售/REITs/长期持有/政府回购
- 若无数据，强制标注"退出路径不明，存在资产沉淀风险"

**步骤11：产品力评估**
- 产品线梳理与标准化程度
- 关键参数：层高/得房率/科技系统/外立面材质
- 产品迭代速度与客户口碑

**步骤12：政商关系与核心资源**
- 政企合作模式、拿地历史、核心人物社会职务
- 标注：G端资源获取能力（强/中/弱）+ 关键人物依赖风险（高/中/低）
- ⚠️ 只用中性表述，禁用推测性词汇

## 装饰行业八大研究维度

| 维度 | 核心问题 | 优先级 |
|------|---------|--------|
| ① 企业整体画像 | 行业格局？谁是头部？什么体量？ | P0 |

| ⑥ 供应链与配套体系 | 采购怎么管？供应链怎么建？ | P0 |
| ⑦ 技术能力与创新壁垒 | 装配式/BIM/数字化护城河？ | P1 |
| ⑧ 企业文化与制度体系 | 管理制度、考核、治理结构 | P1 |

## 装饰行业四大真正壁垒
| 壁垒 | 说明 | 关键指标 |
|------|------|---------|
| 供应链效率 | 集采能力、成本控制、供应商战略关系 | 采购成本占比、前5供应商集中度 |
| 项目管理能力 | 多项目并行、工期控制、质量标准化 | 交付准时率、鲁班奖数量 |
| 产业工人体系 | 稳定施工团队、工种齐全、技能认证 | 自有工人比例、培训体系 |
| 获客成本 | 品牌认知→获客成本低→利润空间大 | 品牌排名、复购率、客户推介率 |

> 研究重点不是"它们现在有什么"，而是"它们怎么一步步建立这些壁垒的"

### 差距分析框架

对标完成后，输出差距分析：

```
我们有什么 → 对标企业有什么 → 差距在哪 → 怎么追
```

每条差距标注：
- **紧迫度**：必须立即解决 / 3个月内解决 / 可以慢慢来
- **难度**：低（花钱能解决）/ 中（需要时间积累）/ 高（需要战略转型）
- **参考路径**：对标企业当年是怎么解决这个问题的

## 从董事长视角思考（四个终极问题）
所有研究最终要能回答：
1. 装饰业务有没有可能做好？（可能性证据）
2. 如果做，和房地产怎么协同？（协同价值）
3. 从零开始要多少钱、多少人、多长时间？（投入产出）
4. 行业里有没有"第二条曲线"？（增量在哪）

---

## 信息不等于洞察
- **交叉验证**：多来源拼在一起，发现别人没看到的关联
- **反向推导**：从招聘信息推业务方向，从供应商名单推供应链策略
- **实地验证**：有机会一定要去现场看——纸面上看不到的往往最重要
